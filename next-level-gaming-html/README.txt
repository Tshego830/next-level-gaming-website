NEXT LEVEL GAMING — HTML & CSS WEBSITE

Open index.html in your web browser. No installation or build is needed.

Pages: index.html, about.html, overview.html, calculate.html, contact.html.
styles.css controls the appearance. arena.js holds the shared package prices
and discount calculations. script.js powers the menu, filters, calculator,
and inquiry form. Photos and the favicon are in assets/.

Keep the files together when copying or uploading the website to a static host.
The fonts load from Google Fonts when online; offline, fallback fonts are used.
The inquiry form opens the visitor's email application. It does not send email
or confirm a booking. Address, telephone, and email are sample information
from the reference screenshots and should be confirmed before launch.
